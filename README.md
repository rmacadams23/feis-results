# Feis Live Results

Live score display for Irish dance competitions: tabulation entry, read-back verification, and a projector display that reveals each adjudicator's Irish points and the final placings.

Open the site: https://rmacadams23.github.io/feis-results/

No-photo edition (for events where photographing score sheets is not allowed): https://rmacadams23.github.io/feis-results/nophotos.html

All competition data is stored only in the browser on the device you use. Nothing is uploaded.
